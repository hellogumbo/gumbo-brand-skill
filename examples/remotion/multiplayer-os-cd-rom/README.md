# Multiplayer OS CD-ROM Video

Runnable Remotion example for the Gumbo Multiplayer OS CD-ROM promo.

```bash
npm install
npm run dev
npm run render
```

- Composition: `multiplayer-os-video`
- Size: `1080x700`
- FPS: `30`
- Duration: `1110` frames
- Render output: `out/multiplayer-os-cd-rom.mp4`

The audio loop is generated locally by `scripts/generate-audio.mjs` before studio/render commands.
